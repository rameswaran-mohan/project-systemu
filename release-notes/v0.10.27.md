# v0.10.27 - consent you can grant and withdraw, and inventory metrics that render

### Added
- **Grant and revoke folder access from the CLI.** `systemu roots grant <path>`
  tells you plainly what granting means (the folder's names and structure become
  surveyable and can appear inside prompts to your model provider), asks for a
  typed yes, and can be withdrawn with `systemu roots revoke <path>`;
  `systemu roots list` shows what stands. Grants are explicit operator consent,
  never automatic.
- **Consent-gated machine census, one category at a time.** `systemu census
  grant|revoke|pause|resume|status` for `cloud_sync_roots`: the real consent
  card is shown first (including that census facts travel inside planning
  prompts to your provider), consent is authenticated to your own vault so a
  stray file can never manufacture it, and revoking both stops future scans
  and removes the facts it produced.
- **Quick-lane ask telemetry.** Every quick-lane question to you is recorded
  as a keyed, non-reversible reference (never the text; secret-class asks are
  excluded twice) so the cap-hit and re-ask rates can be measured; the metrics
  report says NOT MEASURED until there is enough evidence, never a false 0%.
- **The "answered from your table" metric renders.** `systemu debug
  avoidable-ask` now reports inventory hits — pre-filled confirmations and
  silent binds counted separately — and says NOT MEASURED on an empty input.
- **Near-duplicate advisory on every forge path.** Whether a tool is forged
  from the CLI, the dashboard, the daemon's own proposals, self-heal, or the
  sign-off dialog, a near-duplicate of an existing tool is named on the
  record that path already emits.

### Changed
- The tool-approval card states exactly what a standing approval binds to
  (this tool body and effect set; re-forging re-gates it).
- MCP actuation consults the admissibility selector before any call, so the
  hard-deny release gate guards a decision production actually makes.
- The packaged seed vault is checked at commit time so it carries no runtime
  state.
