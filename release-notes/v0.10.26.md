# v0.10.26 - the world scan, the first-run journey, and pages that explain themselves

### Added
- **Scan a folder** (Table page): point Systemu at a folder and it reads file
  names and extensions only — never contents, nothing leaves the machine — and
  offers up to three starter tasks matched to what it saw, each naming your
  folder.
- **Your first-run journey** (Insights): a local-only table of your first-run
  milestones. Counted on this machine only; nothing is sent anywhere.
- **Per-page mini-tours**: a small "?" on core pages opens a two-step guide to
  that page, tuned to how you said you use Systemu. Never auto-opens.
- **"What Systemu can touch"** (Settings): a read-only card stating the
  provider your tiers route to, where your vault lives, tool counts by gate
  state, and capture availability — every line traceable to the code that
  enforces it, with a link to the full privacy page.
- **Home growth card** now says what the week added ("This week: +2 tools"),
  and after your first finished task Home offers a replay of exactly what it
  did — every stage, tool and gate.
- A withheld artifact type in the Outbox receipt now names itself and how to
  open the file deliberately (the suffix is still withheld on delivery: a
  double-click could run that file type's own scripts).

### Changed
- The daemon's multi-instance notice names the ports and vaults involved
  instead of assuming a port race.
- Wish matching counts format vocabulary ("csv", "pdf", "zip"...) and breaks
  ties deterministically.
- Every remaining vault-path lookup resolves through the single vault-root
  authority, so no code path can disagree about where your data lives.
- The guided-tour step parameter rejects lookalike digit forms.
