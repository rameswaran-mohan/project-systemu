# v0.10.28 - a wheel that ships only the seed, and twelve fixes from the first human-style pass

### Fixed
- **`systemu info` names the provider its verdict belongs to.** The OK line
  says which provider will actually serve and, when the configured model
  belongs to a provider that is not set up, says so instead of pairing a green
  verdict with a model that cannot run.
- **`systemu debug avoidable-ask` reads the daemon's inventory snapshots
  wherever you run it from.** The reader and the writer now resolve the audit
  root from the same place instead of the current directory, and a NOT
  MEASURED line names the directory it searched.
- **No rate in that report is fabricated from an empty corpus.** All four
  blocks say NOT MEASURED when there is nothing to measure; none prints
  `0/0 = 0%`.
- The avoidable-ask report and its help speak to an operator: no internal
  ticket or section identifiers in the text.
- The dashboard-extra remedy (`pip install "systemu[dashboard]"`) is printed
  on its own line and never wrapped, so what you copy is what you run.
- **`systemu daemon status` names the port it actually probed and where that
  number came from** (`--port`, the environment, or the default, with the
  remedy when it is a guess), and names the vault root in every verdict.
- **A broken command group is named, never silently dropped.** Each of the
  seventeen command groups registers on its own; if one fails to import, the
  others still load, one line on stderr names the group and the error, and
  invoking the broken group exits 1 with the same line.
- **The near-duplicate advisory now recognises near-duplicates.** Alongside the
  capability-slot check, every forge path compares the proposed tool's name
  and description tokens with the existing catalogue: version suffixes are
  ignored, verb synonyms fold together (fetch/get/read/download, write/save/
  store), and word order does not matter, so `fetch_json_v2`, `json_fetch`,
  and `http_get_json` all name `fetch_json`, and every one of the shipped seed
  tools can be flagged, not only the 18 that had a capability slot. The line
  states which tokens are shared.
- **A withdrawn census consent stays withdrawn.** The consent record is now
  bound to a per-vault consent generation that advances on every revoke, so a
  copy of the consent file taken before a revoke no longer reads as consent
  when restored. Cross-vault transplants and edited grants were already
  refused; a single restored file now is too.
- **Every release wheel now carries exactly the tracked seed vault.** Runtime
  state left on the builder's disk (activity, evolution, notification and
  scroll indexes, elder memory, consent and approval stores, the secrets
  directory, world-model facts, audit and metrics files) is excluded from the
  wheel at build time under both package roots, with `.gitignore` as the oracle:
  a planted file for every ignored path must fail to ship, every tracked vault
  file must still ship, and any untracked file that reaches the wheel fails the
  build test. Releases 0.10.23 through 0.10.27 shipped five empty runtime
  templates; 0.10.28 does not.
- **The analyzer's default model routes through the preset system.** A call
  that names no model resolves the shipped tier-2 / tier-3 preset instead of a
  hardcoded id that had gone stale.
- `fetch_json`'s default User-Agent identifies the package by its PyPI page.
- The MCP actuation refusal cites the section number without a document name.

### Changed
- **One consent prompt for both standing-permission commands.** `roots grant`
  and `census grant` now share the same rule: without a terminal they refuse
  and name `--yes` (exit 2); at a terminal only a typed `y` proceeds, and a
  bare Enter or `n` refuses (exit 1); `--yes` proceeds with the full
  disclosure still printed. Each command's help documents the exit codes.
- `systemu --help` Quick start leads with `systemu start`, the golden path,
  and says the dashboard comes from `pip install "systemu[dashboard]"`.
- The daemon announces the Chromium auto-install before it starts: what is
  downloaded and roughly how large, why (the web tools), the environment
  variable that disables it, and that it runs in the background. The opt-out
  suppresses the download entirely.

### Added
- `scripts/release/ast_equiv.py`: witnesses that a wheel built from the public
  tree is code-equivalent (AST minus docstrings) to the gated tree.
