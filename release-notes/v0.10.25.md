# v0.10.25 — the wishlist, and tool review that arrives with your first task

## Added

- **Capability wishlist.** Write down what you wish Systemu could do — on the
  Table page, next to everything it already has. Wishes are yours to dismiss
  any time, and when the toolbox later gains a matching capability, Home
  quietly points it out: you wished for this, and it is now on the table.
- **Review all tools on demand** — the Build page can bring up the full
  tool-review card whenever you want it.

## Changed

- **Tool review now happens when it matters.** The one-time bulk review card
  no longer appears the moment the daemon starts; it arrives with your first
  task, when the question has context. The card itself — every listed tool,
  the consent record, what batch approval covers and what it never covers —
  is byte-for-byte unchanged, and each tool still asks individually on first
  use, showing its actual arguments.
